# **Genera enemigos**
## **add** funcion:
```kt
fun generateEnemy(): Enemy{
        val enemyWidth = 60f
        val randomX = kotlin.random.Random.nextFloat() *
                (screenWidth-enemyWidth) + enemyWidth/2f
        return Enemy(randomX,0f)
    }
```

## Delay de generacion de enemigos
```kt
LaunchedEffect(gameStarted) {
        while (gameStarted){
            delay(30L)
            if(enemies.size<=2 && screenWidth > 0f){
                enemies = enemies +generateEnemy()
            }
        }
    }
```
